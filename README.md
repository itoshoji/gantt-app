# スケジュール管理

ガントチャート型のタスク管理Webアプリ。Excelで手作業管理していた月次ガント表を
置き換えるために作った、個人用のツール。

**項目 → 中タスク（月単位）→ 小タスク（日単位）** の3階層で予定を持ち、
ガント表・カレンダー・日ごとの一覧を切り替えて見る。仕事とプライベートは
トグルで切り替わり、選んだ側だけが表示される。

## 動かし方

ビルド不要。**`index.html` をダブルクリックすれば動く。**
npm も Node.js も使わない。

データはSupabaseに保存されるので、どの端末から開いても同じ予定が出る。
起動にはログインが要る（利用者は作者ひとり）。

会社のPCなど、URLでアクセスできない環境向けに、CSS/JSを1枚に埋め込んだHTMLも作れる:

```
python3 build_standalone.py 出力先.html
```

## 主な機能

- 年 / 四半期 / 日 の表示切り替え
- セルのダブルクリックで中タスク作成、バーのドラッグで移動・端で伸縮
- **中タスクを動かすと小タスクも同じ月数ずれる**（31日→30日に丸める）
- カレンダーは日をまたぐひと繋がりのバーで描画。週ごとに段を詰める
- 日本の祝日をオフラインで計算（春分秋分の近似式・ハッピーマンデー・振替休日・国民の休日）
- 土曜=うっすら水色 / 日曜・祝日=うっすら赤
- Undo（`Cmd+Z` / `Ctrl+Z`、右クリックメニューからも）
- 項目の並べ替え、非表示

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目 |
| `config.js` | Supabaseの接続情報 |
| `auth.js` | ログイン |
| `holidays.js` | 日本の祝日の計算 |
| `store.js` | データ層（DBに触るのはここだけ） |
| `app.js` | 画面の描画と操作 |

ES Modules は使わず、すべてクラシックスクリプト。`file://` で開いたときに
CORSで止まらないようにするため。
