## デザインの作り直し（2026-07-29）

「カレンダーがごちゃつく」という指摘から、カレンダーと一覧の見た目を作り直した。

調べた定石は3つ:

1. 文字を減らす（1マスに出す行数を絞る）
2. **色を使う面積を減らす**（べた塗りを増やすと色が意味を持たなくなる）
3. 大きさで役割を分ける（日付＝大きく、予定＝小さく、曜日＝控えめに）

**効いたのは2番。** 原因は、ガントのバーは「小タスクが少ないほど淡い色」で描いていたのに、
**カレンダーは全部いちばん濃い設定（`barStyle(color, 5)`）で描いていた**こと。
同じアプリなのにカレンダーだけ色がキツく、並ぶとうるさかった。

現在は両方とも「淡い下地＋左端に色の帯＋濃い文字」で統一している。
その過程で、ガントのバーが持っていた「濃さ＝小タスクの数」という表現は弱めた
（個数はバー右端の数字で読む）。

試行錯誤の順番:

- 1行にしてみた → 「なんの予定かわからん」
- 2行に戻して「項目 / 中タスク」を出した → 「中タスクはいらん」
- **項目名だけの2行に落ち着いた**（中タスク名はマウスを乗せると小窓に出る）

「＋2件」のようにまとめて隠す方式は**本人が明確に拒否**している。
増えたら下にスクロールする。
